# DoughTracker agent instructions

Use the current repository and planning docs for context; a previous chat is not
required. Load only the references relevant to the current task.

For implementation requests, follow the specified handoff under `docs/handoffs/`.
Agents write the implementation, tests and documentation. The owner reviews and
demonstrates understanding of the code that ships; do not assign them a required
coding portion. Follow the readability and comprehension standards in the
current PM workflow. Planning a feature does not itself request implementation.
