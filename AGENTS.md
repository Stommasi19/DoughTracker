# DoughTracker agent instructions

Use the current repository and planning docs for context; a previous chat is not
required. Load only the references relevant to the current task.

The project owner writes and edits all code, tests, and documentation, including
frontend code and project plans. This authorship rule takes precedence over
older handoffs or workflow instructions that assign writing to agents.

AI may create frontend design work such as wireframes, visual mockups, and
interaction concepts. The owner implements those designs.

When asked, AI may also act as a sounding board in conversation. Help the owner
compare options, question assumptions, and assess whether their plan is
realistic and complete. Point out missing steps or dependencies and explain
their impact. The owner makes the decisions and writes any resulting changes.
